AMAL S PRASAD — PERSONAL PORTFOLIO WEBSITE

1. Open index.html in a browser to preview the website.
2. To add social media links, open index.html in a text editor and find:
   const socialLinks = { ... }
   Paste your real profile URLs inside the quotation marks.
3. Add your email in:
   const contactEmail = "";
4. Replace any app descriptions or add Play Store URLs when you have them.
5. Publish free using GitHub Pages:
   - Create/sign in to a GitHub account.
   - Create a public repository named: yourusername.github.io
   - Upload index.html.
   - In repository Settings > Pages, enable deployment from the main branch if needed.
   - Your site will be available at https://yourusername.github.io

NOTES
- No profile photo is included in this starter version.
- Social icons included: Instagram, YouTube, Facebook, GitHub, WhatsApp and X.
- LinkedIn and Pinterest are intentionally excluded.
- App and project descriptions are starter copy and can be edited.
